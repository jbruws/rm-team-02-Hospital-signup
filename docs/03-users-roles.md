# Пользователи

| Роль | Цель | Ключевые действия | Права доступа
| ---- | ---- | ----------------- | ----------- |
| Пациент | Запись на прием к врачу без звонка в регистратуру | • Вход в ЛК<br>• Просмотр свободных талонов<br>• Запись к терапевту и узким специалистам<br>• Перенос и отмена записи<br>• Подтверждение визита | • Видит список свободных талонов к врачам<br>• Видит свои направления<br>• Видит свои записи к врачам |
| Врач | Просмотр записанных пациентов на прием | • Вход в ЛК<br>• Просмотр имеющихся записей<br>• Просмотр причины записи пациента<br>• Выдача электронного направления |• Видит список записанных к нему пациентов (дата, время, ФИО пациента)<br>• Видит причину записи пациента<br>• Может выдать направления к кардиологу/неврологу |
| Регистратор | Управление записями пациентов |• Вход в ЛК<br>• Запись пациента так, чтобы время не пересекалось<br>• Отмена записи<br>• Перенос и отмена записей (по инициативе пациента и врача)<br>• Просмотр направлений |<br>• Видит список прикрепленных к поликлинике пациентов<br>• Видит список свободных талонов к врачам<br>• Видит доступные направления к неврологу/кардиологу у пациента<br>• Видит записи всех пациентов к врачам (ФИО врача, дата, время) |
