# User stories

| ID   | US                                                                                                           | Критерий приемки                                                                        | Обработка ошибок                                               | Связанное требование |
| ---- | ------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------- | -------------------------------------------------------------- | -------------------- |
| US-1 | Как пациент, я хочу иметь возможность посмотреть свободное талоны к нужному врачу, чтобы выбрать подходящее для меня время. | 1. На странице отображаются все возможные свободные талоны, время которых позже текущего момента; 2. Каждый талон содержит точную дату и время, имя врача; 3. Талоны сортируются по дате и времени. | К выбранному врачу нет свободных талонов -  вывести "К выбранному врачу талоны отсутствуют |  [FR-1](02-requirements.md) |
| US-2 | Как врач, я хочу просматривать список записанных пациентов на день, чтобы подготовиться к приему. | 1. Врач должен просматривать список пациентов; 2. Для каждого пациента врач должен просматривать причину визита и историю. | Пациент приходит впервые  к врачу - вывести соответствующее сообщение вместо истории | [FR-8](02-requirements.md),   [FR-9](02-requirements.md) |
| US-3 | Как регистратор, я хочу записывать позвонившего регистратору пациента, чтобы обеспечить доступность записи к врачу для пожилых. | Если пациент звонит в регистратуру, а регистратор находит его и выбирает свободный талон, то запись создана и талон исчезает из свободных для онлайн-записи. | Талон пропадает в ходе звонка - отказать пациенту в регистрации |  [FR-2](02-requirements.md) |
| US-4 | Как пациент, я хочу отменить или подтвердить запись, чтобы избежать санкций за неявку. | 1. Пациенту приходит напоминание о визите сначала в ЛК, затем в SMS; 2. Пациент должен быть способен подтвердить или отменить запись при напоминание. | Не допускать двойной отмены записи через ЛК и SMS одновременно |  [FR-5](02-requirements.md), [FR-10](02-requirements.md) |
| US-5 | Как пациент, я хочу получить SMS-уведомление о своих записях, чтобы не забывать, в какое время у меня прием. | 1. Приходит SMS-уведомление; 2. SMS содержит дату, время, специализацию врача, его ФИО. | Указан неверный номер телефона клиента - сообщение пришло в ЛК |  [FR-10](02-requirements.md) |
| US-6 | Как врач, я хочу иметь возможность видеть причины записи пациента, чтобы ознакомиться с его анамнезом        | Отображается причина записи у врача                                                     | Не указана причина записи - узнать лично на приеме             |
