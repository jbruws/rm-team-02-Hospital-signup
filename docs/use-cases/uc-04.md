# UC-4. Записаться к терапевту

| Поле                    | Значение                                       |
| ----------------------- | ---------------------------------------------- |
| Основное лицо           | Пациент                                        |
| Вспомогательные лица | МИС                               |
| Предусловие             | 1. У пациента есть прикрепление; 2. Пациент зашел через ЕСИА |

## Основной сценарий – через ЛК
1. Пациент выбирает функцию записи к терапевту.
2. Система начинает поиск свободных талонов к терапевтам.
3. Пациент выбирает талон из предложенных.
4. Система повторно проверяет, свободен ли талон.
5. Происходит успешная запись.

## Альтернативный сценарий – талон заняли
4а.1. Система выводит уведомление об отказе в записи.
4а.2. Система предлагает выбрать ближайший талон.
4а.3. Возврат к шагу 4 Основного сценария.

## Исключительный сценарий – отсутствуют свободные талоны к терапевту  
3a.1. Система не находит сободного талона к терапевту.
3а.2. Система выводит уведомление о невозможности записи с указанием причины.
3а.3. Сценарий завершен без записи.

## Исключительный сценарий - у пациента заблокирована онлайн-запись
1a.1. Система выводит уведомление об отказе.
1а.2. Сценарий завершен без записи.

## Исключительный сценарий - МИС недоступна во время записи
5б.1. Система не может соединиться с МИС и отклоняет запрос записи.
5б.2. Система сообщает пациенту, что онлайн-запись невозможна из-за технического сбоя и просит повторить попытку позже.
5б.3. Сценарий завершен без записи.

## Постусловия:
- В случае успеха - произведена запись к терапевту, пришло уведомление об успешной записи.
- В случае неуспеха - запись не произведена, талон остается свободным.
