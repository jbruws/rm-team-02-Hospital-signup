# UC-1. Отменить запись на приём

| Поле                    | Значение                        |
| ----------------------- | ------------------------------- |
| Основное лицо           | Пациент                         |
| Вспомогательные лица | Регистратор (в ветке звонка), МИС                    |
| Вторичные лица  | Врач  |
| Предусловие             | У пациента есть запись на приём |

## Основной сценарий - через ЛК
1. Пациент входит в ЛК.  
2. Пациент выбирает, какую запись нужно отменить.  
3. Система проверяет, сколько осталось времени до приёма.  
4. Система отменяет запись.   
5. Вывод сообщения об успешности запроса.  

## Альтернативный сценарий - отмена записи через звонок
1а.1. Пациент звонит в регистратуру.  
1а.2. Регистратор ищет в системе пациента по ФИО и дате рождения.  
1а.3. Возврат к шагу 3 основного сценария.  

## Альтернативный сценарий - отмена записи через отмену в уведомлении о записи в ЛК
2а.1. Пациент нажимает на отказ отмены записи в ЛК.  
2а.2. Возврат к шагу 3 основного сценария.

## Альтернативный сценарий - отмена записи через SMS-уведомление
1б.1. Пациент открывает ссылку об отмене в ЛК.  
1б.2. Пациент входит в ЛК.  
1б.3. Система открывает конкретную запись.  
1б.4. Возврат к шагу 3 основного сценария.  

## Исключительный сценарий - меньше 2-х часов до приёма
4а.1. В случае если до приёма < 2 часов, система отклоняет запрос отмены записи.  
4а.2. Система сообщает, что онлайн-отмена возможна не более чем за 2 часа до приема.
4a.3. Сценарий завершен без отмены.

## Исключительный сценарий - МИС недоступна во время отмены
4б.1. Система не может соединиться с МИС и отклоняет запрос отмены.
4б.2. Система сообщает пациенту, что онлайн-отмена невозможна из-за технического сбоя и просит повторить попытку позже.
4б.3. Сценарий завершен без отмены.

## Постусловия:
- В случае успеха запись отменена, выведено сообщение об успешности запроса, талон возвращён к статусу "свободен" в случае успешной отмены
- В случае неуспеха запись не отменена, талон остается занятым, пациенту выведено сообщение о причине отказа
