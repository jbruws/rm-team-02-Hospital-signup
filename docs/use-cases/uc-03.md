# UC-3. Просмотреть список записанных к врачу пациентов

| Поле                    | Значение        |
| ----------------------- | --------------- |
| Основное лицо           | Врач            |
| Вспомогательные лица | МИС             |
| Предусловие             | Врач вошел в ЛК |

## Основной сценарий – просмотр списка пациентов
1. Врач выбирает функцию просмотра.
2. Система отображает список записанных к врачу пациентов за текущий день.

## Альтернативный сценарий – нет записей
2а.1. Система выводит сообщение об отсутствии записей.
2а.2. Сценарий завершается.

## Исключительный сценарий - МИС недоступна во время просмотра
2б.1. Система не может соединиться с МИС и выводит врачу соответствующее сообщение.
2б.2. Сценарий завершается.

## Постусловия:
- Выведено сообщение о наличии или отсутствии записей на этот день, либо сообщение об ошибке.
