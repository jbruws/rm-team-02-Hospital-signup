# UC-2. Записаться к узкому специалисту по направлению

| Поле                    | Значение                                              |
| ----------------------- | ----------------------------------------------------- |
| Основное лицо           | Пациент                                               |
| Вспомогательные лица | МИС                                      |
| Предусловие             | 1. У пациента есть прикрепление; 2. Запись через ЕСИА |

## Основной сценарий – через ЛК:
1. Пациент выбирает функцию записи к узкому специалисту.
2. Система из МИС подтягивает действующие направления от лечащего врача.
3. Система начинает поиск свободного талона к специалисту.
4. Пациент выбирает из предложенных.
5. Система повторно проверяет, свободен ли талон.
6. Система производит запись.

## Альтернативный сценарий – талон заняли
5a.1. Система выводит уведомление об отказе в записи.  
5a.2. Система предлагает ближайший свободный талон.  
5a.3. Возврат к шагу 5 Основного сценария.

## Исключительный сценарий – отсутствует/недействительно направление
2a.1. Система выводит уведомление об отказе и предлагает записаться к терапевту.
2а.2. Сценарий завершен без записи.

## Исключительный сценарий – отсутствуют свободные талоны к специалисту
4a.1. Система не находит сободного талона к специалисту.
4а.2. Система выводит уведомление о невозможности записи с указанием причины.
4а.3. Сценарий завершен без запиы.

## Исключительный сценарий - у пациента заблокирована онлайн-запись
1a.1. Система выводит уведомление об отказе.
1а.2. Сценарий завершен без записи.

## Постусловия:
- В случае успеха - произведена запись к узкому специалисту, отослано уведомление о записи
- В случае неуспеха - запись не произведена, талон остается свободным
