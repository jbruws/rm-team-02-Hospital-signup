# UC-2. Запись к узкому специалисту по направлению

| Действующие лица | Пациент, Регистратор, МИС |
|---|---|
| Предусловие | У пациента есть прикрепление, запись через ЕСИА |

## Основной сценарий – через ЛК:
1. Пациент заходит в ЛК.
2. Выбирает функцию записи к узкому специалисту.
3. Система из МИС подтягивает действующие направления от лечащего врача.
4. Начинается поиск свободного талона к спец-ту.
5. Пользователь выбрал из предложенных.
6. Система повторно проверяет свободен ли талон.
7. Происходит успешная запись.

## Альтернативный сценарий – отсутствие/недействительно направление
3a.1. Система выводит уведомление об отказе.

## Альтернативный сценарий – талон заняли
6a.1. Система выводит уведомление об отказе в записи.  
6a.2. Предлагает ближайший свободный талон.  
6a.3. Возврат к шагу 5 Основного сценария.

## Постусловие:
- Произведена запись к узк. специалисту
